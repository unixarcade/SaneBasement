**SANE // THE BASEMENT YEARS** is a single-file generative memory-film by **Luminosity / Matthew Kowalski**.

An aunt takes Sane to her friend’s house. It sounds like one afternoon.

Down the stairs is a basement filled with computers, workbenches, cables, games, photocopied zines, modem signals, strange ideas—and a person who becomes his friend.

Ordinary life remains chaotic. Money, conflict, obligations, accidents, and confusion continue aboveground. But for nearly a decade, the basement becomes a second country: a place where broken machines can be diagnosed, games can be played without apology, unusual knowledge can be passed hand to hand, and two people can quietly share the same problem until it becomes smaller.

The basement does not make the chaos disappear.

It creates a room inside it where life can remain useful, playful, curious, and kind.

## The Story

Sane’s ordinary life contains too many moving parts and no useful manual.

Then his aunt takes him to a friend’s house.

A door opens. Another door opens. The stairs go down.

Each step removes one layer of noise.

Belowground, Sane finds:

* warm lamps and low ceilings,
* computers waiting to be repaired,
* machines that fail for specific reasons,
* real problems that can be touched,
* cables, jumpers, drivers, disks, and printers,
* games used as both testing procedure and celebration,
* photocopied zines carrying unauthorized worlds,
* modem handshakes connecting distant basements,
* and a friendship that never asks him to perform every minute he is alive.

For approximately ten years, work and play occupy the same room.

Machines arrive broken and leave carrying stories. A cursor returns. A disk mounts. A screen stops lying. One more driver is installed. One more impossible cable finally works.

Then comes another game.

Another zine.

Another late night.

Another trip downstairs.

Years pass above the foundation. Computers change. Games change. The stack of magazines grows. Friendship compiles.

Eventually, the physical room becomes an internal one: a low ceiling inside the mind where the lights remain warm and the machines can still be understood.

## A Film About Friendship as Infrastructure

**The Basement Years** is not simply a nostalgia film about old computers.

It is about the places and people that quietly keep a future alive.

The basement provides something ordinary life often cannot:

* continuity,
* scale,
* useful work,
* permission to play,
* shared attention,
* practical learning,
* intellectual freedom,
* and a chair that is still there when you return.

Its central question is small:

> “What are we working on?”

That question does not repair everything.

It restores the size of the world.

Not everything.

Just the next thing.

## Film System

This release is constructed as one self-contained HTML artifact.

```text
procedural cinema
+ synthesized sound
+ adaptive browser voices
+ memory-driven scene architecture
+ executable source
= SANE // THE BASEMENT YEARS
```

### Cinema Engine

* 30 cinematic story movements
* Multiple internal camera setups per scene
* Continuous procedural Canvas animation
* Voice-gated scene progression
* Intra-scene editing and camera movement
* Match cuts and frame-memory transitions
* Push-ins, inserts, close-ups, shutters, apertures, and signal cuts
* Foreground, midground, and background composition
* Half-resolution bloom processing
* Controlled datamosh displacement
* Kintsugi-style signal seams
* Adaptive desktop and mobile layouts
* Reduced-motion support
* Fullscreen playback
* Replay and manual scene navigation

### Visual Worlds

The film generates a distinct visual system for each part of the memory:

* upstairs chaos,
* the aunt’s arrival,
* the stairwell descent,
* basement architecture,
* the shared computer room,
* the repair workbench,
* terminal code,
* floppy-disk stacks,
* photocopied zines,
* game-light and score fields,
* BBS terminals,
* seasonal time compression,
* sanctuary imagery,
* and the final internal basement.

The images are not prerecorded footage. They are assembled during playback from code, geometry, text, particles, light, simulated hardware, memory objects, and cinematic state.

### Voice Constellation

The cast includes:

* **Sane**
* **Aunt**
* **Friend**
* **Narrator**
* **Workbench**
* **Basement System**
* **Modem Ghost**
* **Zine Chorus**

The film dynamically assigns available browser voices to its cast and combines them with character-specific rate, pitch, resonance, breath, width, filtering, and gain behavior.

Scene timing follows the actual spoken performance rather than advancing on a generic timer.

This keeps narration, subtitles, cuts, visual movement, and dialogue-aware sound mixing coordinated as one performance.

The score moves between noise, warmth, work, curiosity, play, network connection, memory, and sanctuary.

## Memory Engines

The film draws on several systems from the larger Luminosity forge architecture:

### ShelVix Memory Crystal

The decade is represented as an interference memory rather than a simple linear recording.

Zines, machines, games, repairs, voices, and rooms refract into later software, films, systems, and worlds.

### NibbleAndByte

Small computational structures become visual machinery: disks, buses, registers, code fragments, timing systems, proof traces, and compact procedural behaviour.

### Living Media

Scenes behave as active environments rather than static illustrations. Foreground, background, typography, light, sound, movement, and story operate as one cinematic organism.

### Speech Forge v9

Voice selection, formant character, speech timing, gain control, subtitles, room placement, and scene progression are coordinated through a single-authority speech architecture.

## Technical Character

This is not a conventional video file embedded in a webpage.

The webpage is the film.

Its graphics, timing, voices, music, effects, subtitles, camera motion, scene cuts, transitions, particles, terminal systems, memory structures, and signal imagery are generated by the browser during playback.

```text
Format:        Single-file HTML
Graphics:      HTML Canvas 2D
Sound:         Web Audio API
Voices:        Browser Speech Synthesis
Interface:     HTML + CSS
Runtime:       JavaScript
Dependencies:  None
Build step:    None
Server:        Optional
```

The project is designed around:

* browser-native execution,
* compact procedural systems,
* inspectable source code,
* deterministic scene structure,
* graceful voice adaptation,
* audio-context-safe startup,
* mobile compatibility,
* low-friction distribution,
* and direct ownership of the finished artifact.

## Run Locally

Clone the repository:

```bash
git clone https://github.com/unixarcade/SaneBasement.git
cd SaneBasement
```

For a clean GitHub Pages deployment, the film should be stored as:

```text
index.html
```

You may also preserve the full studio-master filename:

```text
SANE_THE_BASEMENT_YEARS_AAA_STUDIO_MASTER_v1.html
```

Open the file directly in a modern browser, or launch a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/
```
